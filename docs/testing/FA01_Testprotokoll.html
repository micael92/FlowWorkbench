FA01-T01 Gültige CSV-Datei importieren
  • Anwendung ist installiert und kann gestartet werden.
  • Eine gültige CSV-Datei liegt vor.
  1. Anwendung starten.
  2. Schaltfläche „Datensatz importieren“ auswählen.
  3. Gültige CSV-Datei im Dateidialog auswählen.
  • Die Datei wird erfolgreich geladen.
  • Dateiname, Zeilenanzahl und Spaltenanzahl werden angezeigt.
  • Es erscheint keine Fehlermeldung.
 Die Anwendung wurde erfolgreich gestartet, die CSV-Datei wurde importiert und die vorgesehenen Informationen wurden angezeigt. Bestanden
FA01-T02 Nicht vorhandene oder nicht lesbare Datei laden
  • Anwendung beziehungsweise Import-Funktion ist verfügbar.
  • Ein ungültiger oder nicht vorhandener Dateipfad wird verwendet.
 Import mit einem nicht vorhandenen Dateipfad ausführen.
  • Der Import schlägt kontrolliert fehl.
  • Ein DatasetLoadError wird ausgelöst.
  • Der Fehler wird nicht stillschweigend ignoriert.
 Der automatisierte Test bestätigte, dass beim Import eines nicht vorhandenen Dateipfads ein DatasetLoadError ausgelöst und weitergegeben wurde. Bestanden
FA01-T03 Dateiauswahl abbrechen
  • Anwendung ist gestartet.
  • Der Dateidialog kann geöffnet werden.
  1. Schaltfläche „Datensatz importieren“ auswählen.
  2. Dateidialog ohne Auswahl abbrechen.
  • Es wird kein Import ausgeführt.
  • Es erscheint keine Fehlermeldung.
  • Die Anwendung bleibt geöffnet.
 Der Dateidialog wurde ohne Auswahl abgebrochen. Es wurde kein Import ausgeführt, es erschien keine Fehlermeldung und die Anwendung blieb geöffnet. Bestanden
